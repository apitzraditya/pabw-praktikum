## Pertemuan 4 — Design token halaman Game Favorit Saya
- Tema: Game Favorit / VALORANT
- Berkas gaya: tokens.css, base.css, layout.css, komponen.css, tema.css
- Warna utama: merah VALORANT, dipilih agar identitas halaman game terlihat kuat.
- Token utama:
  - --color-primary: var(--red-700)
  - --color-fg: var(--gray-900)
  - --color-bg: var(--gray-50)
  - --radius-md: 0.5rem
  - --space-4: 1rem
- Uji satu baris: mengubah token warna primitif utama harus memengaruhi tautan, tombol, judul/komponen yang memakai token semantik, dan tema gelap.
- Catatan penggunaan AI: AI digunakan untuk membantu menyusun dan memeriksa struktur CSS/HTML. Penyesuaian tema Game Favorit/VALORANT dan pemeriksaan akhir dilakukan oleh mahasiswa.
